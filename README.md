# Petshop AUmeida
Site de um petshop feito só com HTML5, seguindo o conteúdo das aulas de Fundamentos de Sistemas WEB.

- Site: https://patrikcalmeida.github.io/projetofsweb/
- Código: https://github.com/patrikcalmeida/projetofsweb

## Ajuda:
- **index.html**: página inicial com links para as outras páginas.
- **produtos.html**: produtos e categorias (Acessórios, Rações, Higiene e Limpeza), com imagem, valor e descrição. No cabeçalho tem links para cada categoria.
- **servicos.html**: serviço de banho e tosa, com ou sem tele-busca.

## Pastas
- `imagens/`: fotos usadas em `produtos.html`.
